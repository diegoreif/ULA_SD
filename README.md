The following project aims to develop a 4-bit ALU (Arithmetic Logic Unit) designed in VHDL and ready to run inside a FPGA board,
like Xilinx Spartan 3A/3AN, which it was used to test the project in lab. A debouncing module was also
developed to solve the bouncing problem of the FPGA board's button. The connection between the code and the board is made by top.ucf file.
